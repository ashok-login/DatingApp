📌 Project Title

DatingApp – Full-Stack Web Application

🚀 Overview

DatingApp is a full-stack web application developed using ASP.NET Core 9 and Angular v20. The application demonstrates modern web development practices including RESTful API design, user authentication, and responsive UI development.

This project showcases end-to-end development skills, including backend API development, frontend integration, and database management.

🛠️ Technologies Used

ASP.NET Core Web API

Angular

Entity Framework Core

SQL Server

RESTful APIs

🔑 Key Features

User registration and authentication

Secure login functionality

CRUD operations for user profiles

Responsive UI using Angular

REST API integration between frontend and backend

🏗️ Architecture

The application follows a layered architecture:

Backend: ASP.NET Core Web API for business logic and data access

Frontend: Angular for UI and client-side interaction

Database: SQL Server using Entity Framework Core

▶️ How to Run the Project

Backend

Open the solution in VSCode

Update the connection string in appsettings.json

Run database migrations

Run the Web API project

Frontend

Navigate to the `client` project folder

Run npm install

Run ng serve

Open browser at http://localhost:4200

🎯 Purpose

This project is created to demonstrate full-stack development capabilities using modern technologies like ASP.NET Core and Angular. It highlights API development, frontend integration, and scalable application design.
